---

## 📌 Visão Geral do Curso

O curso abrange desde os fundamentos da lógica de programação e sintaxe da linguagem Java até os pilares da Orientação a Objetos e Tratamento de Exceções, preparando a base para tópicos avançados da plataforma Java.

* **Instrutora:** Loiane Groner
* **Carga Horária Total (Módulo 1):** ~23 horas de aulas práticas e teóricas
* **Foco:** Prática de algoritmos, resolução de exercícios e fundamentos sólidos do Java SE.
